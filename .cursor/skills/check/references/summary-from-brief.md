# Саммари брифа (только бриф)

Эталон структуры — мероприятие **107 ВМ** в Lucy: [summary-brief-template.md](../../lucy/references/summary-brief-template.md).

Для Check отличия:

- Пиши **только** факты из брифа (PDF/текст).
- Не упоминай чек-лист, вкладку, «в ЧЛ стоит».
- Нет данных → «не указано в брифе», не пропускай поле молча, если оно обычно ожидается (гости, объёмы, паспорта).
- Пустой слайд / фото без текста → «в брифе заявлен слайд, содержимого нет».

## Каркас

```markdown
## <код> — <дата> — <площадка>

### Суть

1–2 предложения: формат, кто заказчик/событие, где.

### Ключевые параметры

| Параметр | Значение |
|----------|----------|
| Договор | |
| Дата | |
| Формат | |
| Гости | не указано в брифе / … |
| Команда | |
| Работа | |

### Тайминг

| Этап | Время | Комментарий |
|------|-------|-------------|
| Монтаж | | |
| Мероприятие | | |
| Демонтаж | | |

### Команда

Состав, дресс-код, ФИО если есть.

### Меню и объёмы

Алк. / б/а / пиво / кальяны / докрутка. Если объёма нет — так и напиши.

### Спецэффекты и оборудование

Только упомянутое. Референс-фото помечай как образец формата.

### Площадка и логистика

Адрес из брифа, посуда, мебель, электричество, паспорта, пропуска.

### Контакты

Только роли из брифа.

### Пробелы брифа

Короткий список того, чего в PDF нет (без сверки с ЧЛ).
```

Удали неактуальные секции (нет пива — нет блока пива в меню). «Пробелы брифа» оставляй всегда.
