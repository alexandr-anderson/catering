# Правила валидации чек-листа

Перед выдачей результата проверь каждый пункт. Найденные проблемы — в раздел «Замечания и риски» сводного брифа. Незаполненные поля без данных из брифа — в «Требуется уточнение», **не подставляй значения**.

## Достоверность данных

- [ ] Ни одно поле не заполнено «от себя» — только бриф, шаблон текущего мероприятия или ответ пользователя
- [ ] Нет данных, перенесённых с другого мероприятия
- [ ] Все сомнительные/пустые поля либо спрошены у пользователя, либо явно помечены «требуется уточнение»
- [ ] Расхождения бриф ↔ шаблон не разрешены без ответа пользователя

## Шапка и контакты

- [ ] Номер договора совпадает с брифом
- [ ] Дата корректна
- [ ] Формат мероприятия указан
- [ ] Состав команды указан (старший + N барменов)
- [ ] Все 4 контакта заполнены: кейтеринг, продажи, заказчик, **площадка**
- [ ] Телефоны в едином формате

## Площадка

- [ ] Адрес — из брифа, не из названия вкладки Sheet
- [ ] Комментарии: этаж, ограничения заезда, паспорта
- [ ] Пропуска: дедлайн и что нужно (авто, ФИО)
- [ ] Электричество: «Да» + мощность/розетки, если есть в брифе
- [ ] Мебель и посуда согласованы (Да/Нет + комментарий)

## Тайминги

- [ ] Прибытие / монтаж
- [ ] Окно заноса (если ограничено)
- [ ] Время мероприятия (начало–конец)
- [ ] Демонтаж после окончания
- [ ] Тайминги не противоречат брифу

## Объёмы и услуги

- [ ] Алк. и б/а коктейли — правильные числа
- [ ] Пиво / доп. позиции — если есть в брифе
- [ ] Строка докрутки — если есть в брифе (до N порций, какие напитки, судьба алкоголя)
- [ ] Часы работы персонала согласованы с таймингом

## TTK

- [ ] Все напитки из брифа присутствуют в блоке АЛК
- [ ] Все б/а версии — в блоке БА
- [ ] Mojito БА **без рома**
- [ ] Clover Club БА — с белком, без джина
- [ ] Инструкции с азотом — там, где в брифе указан азот
- [ ] Крафт-лёд и оттиск — в нужных напитках (Negroni, Basil Smash, Old Fashioned)
- [ ] Бластер — для Clover Club (алк. и б/а)

## Спецоборудование

- [ ] Сосуд Дюара / азот — если в брифе
- [ ] Коктейльный бластер
- [ ] Латунный оттиск + комментарий «отдать заказчику»
- [ ] Пивное оборудование — если есть пиво

## Документы и персонал

- [ ] Строка «Паспорта сотрудников» — обязательна
- [ ] Количество паспортов = числу членов команды

## Согласованность

- [ ] Суммы ингредиентов в закупке согласованы с TTK
- [ ] Посуда: количество бокалов ≥ объёмам напитков
- [ ] Нет данных от **другого** мероприятия, оставшихся в шаблоне

## Финальная проверка

- [ ] CSV сохранён в `checklists/<slug>-checklist.csv`
- [ ] Сводный бриф сохранён в `briefs/<slug>-summary.md`
- [ ] Сводный бриф содержит только подтверждённые факты; неизвестное — в «Требуется уточнение»
- [ ] Пользователю заданы все накопленные вопросы по неизвестным полям (если такие есть)
