# Маппинг: бриф → чек-лист

## Общие правила

1. **Бриф — источник истины.** Шаблон — каркас; не переноси из шаблона данные прошлого мероприятия.
2. **Не удаляй строки шаблона** — очищай или перезаписывай значения.
3. **Комментарии** — в колонку «Комментарии» или аналог; туда же нестандартные условия из брифа.
4. Если поле в брифе отсутствует — оставь пустым и отметь в сводном брифе.

## TTK (технологические карты)

### Алкогольные напитки

Переноси в блок **«Раскладка напитков АЛК»**:

- Название напитка
- Ингредиенты с дозировками
- Бокал, тип льда, техника, декор
- Пошаговая инструкция (в т.ч. азот, если указан)

### Безалкогольные

Отдельный блок **«Раскладка напитков БА»**:

- Суффикс «БА» в названии
- **Без алкоголя** в ингредиентах (Mojito БА — без рома)
- Остальная техника — как у алк. версии, если не указано иное

### Спецподачи

| Эффект | Где отразить |
|--------|--------------|
| Жидкий азот | TTK (инструкция), оборудование (сосуд Дюара), оплаченные услуги |
| Крафт-лёд + оттиск | TTK (тип льда), ингредиенты (100 кубов), отдельная строка оттиска |
| Бластер | TTK Clover Club, инвентарь |
| Пивной драфт | Секция пивного оборудования + оплаченные услуги |

## Количественные расчёты

Если бриф даёт только объёмы напитков, а не ингредиенты:

- Используй TTK из шаблона как формулы (мл × кол-во порций)
- Пересчитай «Итого» в пребатчах и закупке
- Лёд: ориентир **20 кг на 100 напитков** + крафт-кубы по брифу

## Именование вкладки Sheet

Вкладку **не переименовывай** без запроса. Если название вкладки не совпадает с адресом — зафиксируй в сводном брифе, в CSV используй **адрес из брифа**.
