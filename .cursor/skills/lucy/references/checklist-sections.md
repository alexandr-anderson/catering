# Структура секций чек-листа

Типичный шаблон Google Sheet состоит из следующих блоков (сверху вниз). Нумерация строк может отличаться — ориентируйся на **заголовки секций**.

## 1. Шапка

| Поле | Пример |
|------|--------|
| Номер договора | 107 ВМ |
| Дата и время | 25.08.26 |
| Формат | Коктейльный бар |
| Количество гостей | (если указано в брифе) |
| Количество сотрудников | 1 старший + 3 бармена |
| Данные от заказчика | краткое описание события |

## 2. Контакты по мероприятию

- Менеджер по кейтерингу (имя, телефон)
- Менеджер отдела продаж
- Заказчик
- **Представитель площадки** — часто пропускают; брать из брифа

## 3. Данные о площадке

- Название площадки
- Точный адрес
- Комментарии (этаж, ограничения заезда, паспорта)
- Заезд / пропуска
- Зона разгрузки и удалённость
- Согласованная мебель
- Согласованная посуда
- Подключение к электричеству

## 4. Тайминги

- Прибытие на площадку
- Подготовка к мероприятию
- Мероприятие (начало–конец)
- Сбор, подсчёт посуды, упаковка

## 5. Персонал

Таблица: ФИО, должность, телефон, ник в соцсетях. Строки под старшего и барменов — заполняются перед выездом или оставляются пустыми с указанием количества.

## 6. Оплаченные услуги

Строки с объёмами:

- Работа сотрудников (состав + часы)
- Алкогольные / б/а коктейли (шт.)
- Комплект крепкого алкоголя
- Эффектные подачи (лёд, оттиск, азот, бластер)
- Пивное оборудование и пиво
- Логистика

Отдельная строка **«ВАЖНО: докрутка б/а → алк.»** — если есть в брифе.

## 7. Текстиль, инвентарь, оборудование

Количества считаются от числа сотрудников и напитков. При сомнении — оставь формулы/комментарии из шаблона, обнови только явно указанные в брифе позиции.

## 8. Жидкий азот / спецоборудование

- Сосуд Дюара
- Термосы, чайник
- Латунный оттиск (с комментарием кому отдать)
- Коктейльный бластер

## 9. Хозка, посуда

Объёмы посуды — от меню и количества напитков.

## 10. Ингредиенты, пребатчи, декор

Заполняются из TTK. Секции:

- Ингредиенты для упаковки
- Ингредиенты для пребатчей
- Декор

## 11. Документы

- Чек-лист (копия)
- Распечатка раскладки
- Карта упаковки
- **Паспорта сотрудников** — обязательная строка

## 12. Раскладка напитков

Два блока:

- **Раскладка напитков АЛК**
- **Раскладка напитков БА**

Каждый напиток: ингредиенты, бокал, лёд, техника, декор, пошаговая инструкция.

## 13. Закупка ингредиентов

Сводная таблица для закупки — агрегат из TTK.
