# Как прочитать нужную вкладку Google Sheet

Check **только читает**. Запись в Sheet, загрузка CSV «для импорта» и правки `checklists/` запрещены.

## ID таблицы

```
https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/edit#gid=<TAB_GID>
```

- `SPREADSHEET_ID` — для Drive MCP и URL экспорта
- `TAB_GID` — если есть в ссылке, можно экспортировать по `gid`

Название вкладки пользователь даёт текстом — сверяй его со списком листов.

## Что не работает как ожидается

| Способ | Ограничение |
|--------|-------------|
| Google Drive MCP `read_file_content` | Часто отдаёт **имена листов** без содержимого ячеек |
| MCP `download_file_content` + `text/csv` | Экспортирует **первый** лист книги, не выбранную вкладку |
| Импорт CSV пользователем | Для Check **не предлагать** |

## Надёжное чтение указанной вкладки

1. Возьми `SPREADSHEET_ID` из URL.
2. Экспортируй CSV **по имени листа** (UTF-8 URL-encode):

```
https://docs.google.com/spreadsheets/d/<ID>/gviz/tq?tqx=out:csv&sheet=<ИМЯ_ВКЛАДКИ>
```

3. Если gviz недоступен — скачай xlsx (`export?format=xlsx` или MCP `exportMimeType` xlsx) и открой лист по имени.
4. Если вкладки нет в книге — остановись, покажи список листов, попроси точное имя.

Проверка, что это тот лист: в шапке должны быть договор / дата / формат, близкие к брифу. Если в шапке чужое мероприятие — не сверяй «как есть», сообщи о несовпадении вкладки.

## Комментарии в Sheet

Если MCP умеет `includeComments` — включи. Иначе сверка идёт по значениям ячеек.
