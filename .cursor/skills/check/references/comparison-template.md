# Шаблон блока сверки

В чате и в `briefs/<slug>-check.md` сверка идёт **после** саммари, отделённая заголовком. Не смешивай блоки.

```markdown
---

## Сверка с вкладкой `<точное имя>`

Источник: Google Sheet `…`, вкладка считана (строк: N). Чек-лист не изменялся.

### Совпадает

- …

### Расхождения

| Поле | Бриф | Чек-лист |
|------|------|----------|
| | | |

Если расхождений нет — напиши «нет».

### Есть в брифе, в чек-листе нет или неполно

- …

### Есть в чек-листе, в брифе нет

Не подтверждено брифом (шаблон, расчёт или догадка):

- …

### Требуется уточнение

1. … (по расхождению: что считать верным?)
2. … (дыра в брифе)
```

Не предлагай «внесу в вкладку» и не прикладывай инструкцию импорта CSV.

Критичные конфликты (тайминг заезда, кВт, объёмы напитков, паспорта, адрес) перечисляй первыми в таблице расхождений.
